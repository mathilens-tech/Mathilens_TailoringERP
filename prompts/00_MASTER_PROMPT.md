## Purpose

This is the top-level working prompt for AI-assisted development on Mathilens Tailoring ERP. It sets shared context (product intent, constraints, quality bar) that other prompts in this directory build on.

## Product Context

Mathilens Tailoring ERP is a production-grade, commercial multi-tenant ERP product for tailoring shops. All work should meet enterprise production-quality standards — see [../docs/00_MASTER_SPEC.md](../docs/00_MASTER_SPEC.md) and [../docs/09_CODING_STANDARDS.md](../docs/09_CODING_STANDARDS.md).

## How to Use These Prompts

Each numbered prompt in this directory corresponds to a module or workstream. They are intended to be used sequentially as the product is built out, starting with project setup and database foundations before module-specific work.
