# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Mathilens Tailoring ERP, please report it responsibly.

- Do **not** open a public GitHub issue for security vulnerabilities.
- Contact the maintainers privately with a description of the issue, steps to reproduce, and potential impact.
